# FAQ Chatbot Using NLP

## Project Overview
A smart FAQ chatbot developed using Python,
Streamlit and Natural Language Processing techniques.

## Features
- Interactive chatbot interface
- Automatic FAQ matching
- Text preprocessing
- TF-IDF vectorization
- Cosine similarity
- Instant answers
- Conversation reset

## Technologies
- Python
- Streamlit
- Pandas
- Scikit-learn
- NLP

## Installation

pip install -r requirements.txt

## Run Application

streamlit run app.py
